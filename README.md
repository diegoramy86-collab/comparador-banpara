# Comparador Banpará

Programa de consulta das tarifas do Banco do Estado do Pará (âncora) frente aos bancos-parâmetro.

Não precisa instalar Python para ver. O arquivo que abre em qualquer celular e computador é o `index.html`.

## Como abrir agora (sem GitHub)

1. Baixe esta pasta.
2. Toque / dê dois cliques em `index.html`.
3. Abre no Safari, Chrome ou Edge.

## Como deixar online (resolve o “não abre”)

1. Crie um repositório no GitHub (pode ser privado).
2. Envie estes arquivos para o repositório.
3. Settings → Pages → Deploy from branch → `main` → pasta `/ (root)`.
4. O GitHub gera um endereço do tipo  
   `https://SEUUSUARIO.github.io/comparador-banpara/`
5. Esse endereço é o que você manda no WhatsApp ou cola no Google.

## O que tem neste programa

- Aba Relação: o que é igual, parecido ou não compara
- Aba Oficiais cruzados: Banpará × Banestes, Banese, Banrisul, Safra, BB e outros
- Abas PF e PJ: valores oficiais do Banpará (vigência 22/06/2026)
- Busca no topo

## Bancos-parâmetro

Banpará (âncora), BASA, BNB, BRB, Banese, Banestes, Banrisul, Caixa, Banco do Brasil, Bradesco, Santander, Itaú Unibanco, Safra.

BASA, BNB e BRB ainda estão sem PDF oficial nesta versão.
